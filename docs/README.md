## Overview

Read structured lessons in sequence or look up topics. The reader supports search, notes, bookmarks, favorites and browser-based reading progress. The interface is bilingual; all four courses are available in German and English.

Die Lerntexte lassen sich der Reihe nach lesen oder gezielt nachschlagen. Der Reader bietet Suche, Notizen, Lesezeichen, Favoriten und persönlichen Lesestand. Die Oberfläche ist zweisprachig; alle vier Kurse liegen auf Deutsch und Englisch vor.

### Two ways to use the courses / Zwei Nutzungsformen

**Web reader:** Open `index.html` or the course link. Features include search, lesson navigation, reading progress, favorites, bookmarks, notes, adjustable font size and light/dark mode. The complete offline edition works without a server after extraction. No registration; reading data stays in the browser and can be exported, imported or deleted per course. All local Learning Courses data, including shared settings, can also be deleted.

**Markdown documents:** Individual documents in the subject repositories’ `master/` folders have extensive YAML frontmatter for automatic or manual categorization and ordering.

| Field | Meaning |
|---|---|
| `document_id` | Unique document identifier across courses |
| `series_id` | ID of the first course document |
| `series_part` | Consecutive position starting at 1 |
| `document_version` | Document version |
| `language`, `study_level` | Language and education level |
| `categories`, `keywords` | Categories and keywords |
| `author`, `license` | Attribution and license |
| `website`, `github` | Website and subject repository |

**Webreader:** Einstieg über `index.html` oder den Kurslink. Der Reader bietet Suche, Kapitel- und Lektionsnavigation, Lesefortschritt, Favoriten, Lesezeichen, persönliche Notizen, Schriftgrößenanpassung und Hell-/Dunkelmodus. Die vollständige Offline-Ausgabe funktioniert nach dem Entpacken ohne Server. Keine Registrierung; Lesedaten bleiben lokal im Browser und lassen sich pro Kurs exportieren, importieren oder löschen. Auch alle lokalen Learning-Courses-Daten einschließlich gemeinsamer Einstellungen können gelöscht werden.

**Markdown-Dokumente:** Die einzelnen Kursdokumente in `master/` der Fach-Repositories besitzen umfangreiche YAML-Frontmatter-Metadaten, die eine automatische oder manuelle Zuordnung und Sortierung ermöglichen.

| Feld | Bedeutung |
|---|---|
| `document_id` | Kursübergreifend eindeutige Dokumentkennung |
| `series_id` | Document-ID des ersten Kursdokuments |
| `series_part` | Fortlaufende Position ab 1 |
| `document_version` | Dokumentversion |
| `language`, `study_level` | Sprache und Bildungsniveau |
| `categories`, `keywords` | Kategorien und Schlagwörter |
| `author`, `license` | Urheber und Nutzungslizenz |
| `website`, `github` | Website und Fach-Repository |
