Lokal gespeicherte Reader-Daten

Der Reader speichert Notizen, Favoriten, Lesezeichen, Lesestand und Darstellungseinstellungen im jeweiligen Browser, damit sie beim nächsten Öffnen weiterhin verfügbar sind. Ein Benutzerkonto oder eine Übertragung dieser Inhalte an den Herausgeber ist dafür nicht erforderlich. Die Daten können im Browser gelöscht oder mit der Exportfunktion selbst gesichert werden. Für das Speichern und Auslesen von Informationen auf dem Endgerät gilt § 25 TDDDG. Die Ausnahme für unbedingt erforderliche Funktionen setzt voraus, dass der Nutzer den jeweiligen Dienst ausdrücklich wünscht.

Es ist kein Benutzerkonto für das Lesen oder für diese lokalen Funktionen erforderlich. Die aktuelle Reader-Anwendung überträgt persönliche Notizen, Favoriten und Lesestände nicht selbsttätig an den Herausgeber oder GitHub. Browser-Synchronisation und Erweiterungen können unabhängig davon arbeiten.

Website-Hosting über GitHub Pages

Beim Abruf der über GitHub Pages bereitgestellten Onlinefassung werden technische Verbindungsdaten an den Hostinganbieter übertragen. GitHub beschreibt insbesondere die Verarbeitung von IP-Adressen im Rahmen von Sicherheitsmaßnahmen. Diese Verarbeitung ist von den lokal gespeicherten Lernständen getrennt.
