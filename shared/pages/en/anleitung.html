User guide

This course can be read without an account or an internet connection. The interface works on computers, tablets and smartphones. On smaller screens, the tables of contents open through the Course and Chapters buttons.

1. Read and find lessons

Select a lesson in the course overview on the left. The search field filters lessons as you type. Use “Previous” and “Next” to switch between units. “Mark as read” stores reading progress in this browser. The bottom of the left sidebar shows “Lessons read: 0 of …” with the current count of completed lessons.

2. Favorites

Use the star beside a lesson heading to save an entire lesson as a favorite or remove it by clicking again. The Favorites menu in the top bar displays the list in insertion order; adding a lesson again moves it to the end. Clicking an entry opens that lesson.

3. Section bookmarks

Bookmark symbols are displayed beside lesson headings and section headings. A click adds or removes a bookmark. In the bookmark menu, the lesson heading groups the relevant entries. If the lesson start has been bookmarked, that entry can be removed with its own ✕ without deleting other section bookmarks. The list is grouped by lesson and section. Clicking an entry opens the saved position; clicking outside closes the list.

4. Notes on lessons, sections and text passages

A pencil icon beside the lesson heading (H1) creates a note about the entire lesson; beside section headings it creates a section note. The note dialog allows you to write and save without shifting the reading text or other notes. The Notes tab on the right places saved note cards alongside their sections. Note cards grow with the text until the space before the next section is reached, and then allow internal scrolling. Use ✎ to edit or ✕ to delete after confirmation. On narrow screens, the notes appear in a side menu instead. Each note has the lesson and, where applicable, the section title, with editing and deletion controls at the upper right. The bottom-right area shows the number of notes stored for the course.

5. Export notes

Use “Reading data” → “Save reading progress” in the top bar to save notes as Markdown (MD), including lesson and section titles, quotations and timestamps. To re-import notes later, select the Notes category in a JSON backup. Keep downloaded backup files yourself.

6. Save, load and delete reading progress

“Reading data” opens a shared dialog. Its “Save reading progress” section offers read marks, favorites, bookmarks and notes. All categories are selected by default; individual categories can also be saved as JSON. “Load reading progress” validates the JSON file and displays the available categories for selection. With “Keep existing data” enabled, new entries are added and matching entries overwritten. Otherwise, after confirmation, all existing reading data for the current course is replaced with the selected backup data. Other courses and settings are unchanged. Results are displayed in the corresponding section of the dialog. “Delete reading data” provides a separate confirmed action to delete local reading data for the current course or all courses, including shared settings.

7. Font size and column width

The magnifier buttons reduce or enlarge the reading font. The chosen size is stored in the browser. The ↔ button switches the reading area between narrow and wide; ▥ changes the width of the side columns. On smartphones, the layout automatically switches to a more compact view. Typography and layout settings can also be adjusted using the Reader's settings panel and exported as JSON.

8. Light and dark mode

The moon or sun button changes the colors of the interactive reader. The reader requires JavaScript; separate static course-lesson pages are not included in this edition. Notes and progress remain stored locally in the browser.

9. Storage and privacy

Reading progress and notes are kept in local browser storage, not in an account or on a server. Different browsers, profiles, devices or local file paths may have separate storage. Deleting browser data or using private mode may cause data loss. Save a JSON backup regularly. For further information, see Privacy policy.
